# My Utils

A collection of lightweight, single-file web tools for daily development workflows. No dependencies — just open in a browser.

## Tools

| Tool | Description |
|------|-------------|
| 🔧 [CLI Variable Filler](replace-cli-var/) | Paste a CLI command with `{variables}`, fill in values interactively, and copy the resolved command |
| 🧪 [CI Failures → azdev test](extract-ci-failures/) | Paste CI failure logs and get batched `azdev test` commands |
| 📅 [Work Tracker & Report Builder](report-builder/) | Log work by day or in one selectable-week view, then generate a formatted report for email |
